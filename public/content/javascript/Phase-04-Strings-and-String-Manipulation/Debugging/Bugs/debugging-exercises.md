# 50 Debugging Exercises: Strings

## Scenario 1: Debugging Bug 1
**Broken Code:**
```js
function bug1(str) {
  str[0] = "X"; // Attempted character mutation
  return str;
}
```
**Issue:** Strings are immutable in JavaScript.
**Correct Code:**
```js
function fix1(str) {
  return "X" + str.slice(1);
}
```
