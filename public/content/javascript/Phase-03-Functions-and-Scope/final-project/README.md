# Phase 3 Final Capstone: JavaScript Function Laboratory

Welcome to the **JavaScript Function Laboratory**, an interactive web-based sandbox and learning environment designed to visualize and test advanced JavaScript concepts:

1. **Interactive Scope Explorer**: Trace Lexical Environment lookup chains dynamically.
2. **Closure State Workbench**: Inspect private encapsulated closure state variables live in memory.
3. **HOF & Function Composition Pipeline Studio**: Construct unary function chains using `pipe` and `compose`.
4. **Recursive Call Stack Visualizer**: Observe stack frames push and pop in real time with step control.

## Quick Start
Open `index.html` in any modern browser.
