# Expected Output: JavaScript Function Laboratory

When interacting with the JavaScript Function Laboratory:

1. **Scope Explorer Tab**: Clicking "Trace Identifier Lookup" displays 3-level scope lookup trace.
2. **Closure Workbench Tab**: Clicking "Increment Counter" increments private closure state.
3. **Pipeline Studio Tab**: Clicking "Run Pipe" calculates `pipe(double, add10, square)(3) = 256`.
4. **Recursion Visualizer Tab**: Clicking "Run Factorial" displays stack push and pop lifecycle for `fact(5) = 120`.
