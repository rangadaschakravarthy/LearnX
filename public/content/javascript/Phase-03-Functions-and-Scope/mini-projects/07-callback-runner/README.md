# Mini-Project 7: Callback Task Runner & HOF Benchmarking

## Overview
Task scheduler runner demonstrating custom `myMap`, `myFilter`, `myReduce`, debouncing, and throttling.

## Features
- Modern glassmorphism UI styled with CSS variables.
- Fully interactive controls.
- Zero dependencies.

## How to Run
Open `index.html` in any web browser or use live-server.
