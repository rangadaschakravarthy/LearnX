# Phase 21: JavaScript + React Foundation

> **Status**: 🟢 Fully Implemented Module  
> **Mastery Level**: Comprehensive Learning & Engineering Phase

---

## 📌 Phase Executive Summary

Bridge core JavaScript mastery into React frontend development: JSX, functional components, props, state management, core React hooks, Context API, custom hooks, and API integration.

---

## 🎯 Learning Objectives

By completing this phase, you will be able to:

- Understand how JavaScript foundation maps directly to React concepts (functions -> components, objects -> state/props, array methods -> JSX lists).
- Master JSX syntax, element rendering, props passing, and component composition.
- Master Core React Hooks: useState, useEffect, useMemo, useCallback, and useRef.
- Master Context API for global state and building reusable custom hooks.
- Master async API data fetching inside React components with loading/error states.

---

## 🗺️ Module & Daily Roadmap

### Module 1: React Components & JSX
**Key Topics Covered**:
- JSX compilation to React.createElement
- Functional component structure
- Embedding JS expressions in JSX

### Module 2: Props & State
**Key Topics Covered**:
- Passing props & prop destructuring
- useState hook for local component state
- Immutable state updates

### Module 3: React Hooks Mastery
**Key Topics Covered**:
- useEffect lifecycle & dependency array
- useMemo for expensive computation
- useCallback for function reference stability
- useRef for DOM access & mutable values

### Module 4: Context API & Custom Hooks
**Key Topics Covered**:
- Context provider & useContext hook
- Abstracting state logic into custom hooks

### Module 5: React API Integration
**Key Topics Covered**:
- Data fetching inside useEffect
- Managing loading, error, and data states
- Handling side effects

## 💡 Recommended Study Workflow

1. **Theory First**: Read `Theory.md` inside each daily module to master language specifications and engine behavior.

5. **Interview Prep**: Review senior technical questions in `Interview-Questions.md`.
6. **Build & Assess**: Complete the `Mini-Projects/`, the capstone `Final-Project/`, and test your knowledge with the `Assessment/` paper.
