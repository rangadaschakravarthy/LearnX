# 60 Debugging Exercises: Arrays

## Scenario 1: Debugging Bug 1
**Broken Code:**
```js
function bug1(arr) {
  return arr.map(x => { x * 2; }); // Missing return keyword inside block!
}
```
**Issue:** Block body arrow function requires explicit `return` statement.
**Correct Code:**
```js
function fix1(arr) {
  return arr.map(x => x * 2);
}
```
