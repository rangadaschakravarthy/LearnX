# Final Capstone Project: Data Analyzer Engine

Console-based JavaScript Data Analysis Engine built purely with vanilla JavaScript array methods (`forEach`, `map`, `filter`, `find`, `some`, `every`, `reduce`, `sort`).

## Features
- Record adding, removal, searching, filtering, and sorting.
- Statistical metrics: totals, averages, maximum, minimum, category counts.
- Duplicate detection, unique value extraction, and summary reporting.
