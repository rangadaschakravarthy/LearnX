# Phase 08: DOM & Browser JavaScript

> **Status**: 🟢 Fully Implemented Module  
> **Mastery Level**: Comprehensive Learning & Engineering Phase

---

## 📌 Phase Executive Summary

Master the Document Object Model (DOM): selecting nodes, manipulating content and CSS classes, creating/removing DOM elements, handling events, and understanding event propagation.

---

## 🎯 Learning Objectives

By completing this phase, you will be able to:

- Understand the DOM tree representation and node hierarchy.
- Master element selection: getElementById(), querySelector(), querySelectorAll().
- Master content and attribute manipulation: textContent, innerText, innerHTML, setAttribute(), classList.
- Master element creation & removal: createElement(), appendChild(), append(), remove().
- Master browser event handling: addEventListener(), click, keydown, submit events.
- Master Event Propagation: Event Bubbling, Event Capturing, Event Delegation, stopPropagation(), and preventDefault().

## 🗺️ Module & Daily Roadmap

### Day 26: DOM Basics & Selection
**Key Topics Covered**:
- DOM tree hierarchy
- getElementById & getElementsByClassName
- querySelector & querySelectorAll
- NodeList vs HTMLCollection

### Day 27: Manipulating DOM
**Key Topics Covered**:
- textContent vs innerText vs innerHTML
- getAttribute & setAttribute
- classList (add, remove, toggle, contains)

### Day 28: Creating & Removing Elements
**Key Topics Covered**:
- createElement()
- appendChild() vs append()
- remove() & removeChild()
- Cloning elements with cloneNode()

### Day 29: Events & Listeners
**Key Topics Covered**:
- addEventListener() & removeEventListener()
- Mouse events (click, dblclick, mouseover)
- Keyboard events (keydown, keyup)
- Form events (submit, input, change)

### Day 30: Event Propagation & Delegation
**Key Topics Covered**:
- Event Bubbling phase
- Event Capturing phase
- Event Delegation pattern
- stopPropagation() & preventDefault()
- e.target vs e.currentTarget
