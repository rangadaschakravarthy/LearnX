# Day 09 — Events and Event Listeners

## Overview
Welcome to **Day 09 — Events and Event Listeners**. This module teaches the fundamentals of What is an event?, Event-driven programming, addEventListener(), removeEventListener(), Named vs Anonymous handlers, Basic mouse events (click, dblclick, mouseenter, mouseleave).

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply What is an event?
- Understand and apply Event-driven programming
- Understand and apply addEventListener()
- Understand and apply removeEventListener()
- Understand and apply Named vs Anonymous handlers
- Understand and apply Basic mouse events (click, dblclick, mouseenter, mouseleave)
