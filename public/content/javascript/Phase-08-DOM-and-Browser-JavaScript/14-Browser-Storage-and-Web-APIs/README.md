# Day 14 — Browser Storage and Web APIs

## Overview
Welcome to **Day 14 — Browser Storage and Web APIs**. This module teaches the fundamentals of localStorage & sessionStorage API, setItem, getItem, removeItem, clear, JSON.stringify & JSON.parse, location API, history API basics, navigator API.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply localStorage & sessionStorage API
- Understand and apply setItem, getItem, removeItem, clear
- Understand and apply JSON.stringify & JSON.parse
- Understand and apply location API
- Understand and apply history API basics
- Understand and apply navigator API
