# Day 04 — Reading and Modifying Elements

## Overview
Welcome to **Day 04 — Reading and Modifying Elements**. This module teaches the fundamentals of textContent, innerText, innerHTML, value property, Reading & modifying element content, Security risks of innerHTML & XSS prevention.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply textContent
- Understand and apply innerText
- Understand and apply innerHTML
- Understand and apply value property
- Understand and apply Reading & modifying element content
- Understand and apply Security risks of innerHTML & XSS prevention
