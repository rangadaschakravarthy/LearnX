# Day 05 — Attributes and Data Attributes

## Overview
Welcome to **Day 05 — Attributes and Data Attributes**. This module teaches the fundamentals of getAttribute(), setAttribute(), removeAttribute(), hasAttribute(), Property vs Attribute, data-* attributes, dataset API.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply getAttribute()
- Understand and apply setAttribute()
- Understand and apply removeAttribute()
- Understand and apply hasAttribute()
- Understand and apply Property vs Attribute
- Understand and apply data-* attributes
- Understand and apply dataset API
