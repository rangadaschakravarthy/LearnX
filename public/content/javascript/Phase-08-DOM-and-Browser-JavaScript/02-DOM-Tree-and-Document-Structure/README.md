# Day 02 — DOM Tree and Document Structure

## Overview
Welcome to **Day 02 — DOM Tree and Document Structure**. This module teaches the fundamentals of DOM Tree concept, Document Node, Element Nodes, Text Nodes, Parent, Child & Sibling nodes, childNodes vs children, DOM representation of HTML.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply DOM Tree concept
- Understand and apply Document Node
- Understand and apply Element Nodes
- Understand and apply Text Nodes
- Understand and apply Parent, Child & Sibling nodes
- Understand and apply childNodes vs children
- Understand and apply DOM representation of HTML
