# Day 13 — Keyboard, Mouse and Input Events

## Overview
Welcome to **Day 13 — Keyboard, Mouse and Input Events**. This module teaches the fundamentals of Keyboard events (keydown, keyup), key, code, ctrlKey, shiftKey properties, Mouse movement events, input vs change events, focus & blur events, Keyboard shortcuts.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply Keyboard events (keydown, keyup)
- Understand and apply key, code, ctrlKey, shiftKey properties
- Understand and apply Mouse movement events
- Understand and apply input vs change events
- Understand and apply focus & blur events
- Understand and apply Keyboard shortcuts
