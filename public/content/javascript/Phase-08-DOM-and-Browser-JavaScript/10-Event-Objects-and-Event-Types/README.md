# Day 10 — Event Objects and Event Types

## Overview
Welcome to **Day 10 — Event Objects and Event Types**. This module teaches the fundamentals of Event object properties, target vs currentTarget, preventDefault(), stopPropagation(), Common event types (click, input, change, submit, focus, blur).

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply Event object properties
- Understand and apply target vs currentTarget
- Understand and apply preventDefault()
- Understand and apply stopPropagation()
- Understand and apply Common event types (click, input, change, submit, focus, blur)
