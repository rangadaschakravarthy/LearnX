# Day 11 — Event Bubbling, Capturing and Delegation

## Overview
Welcome to **Day 11 — Event Bubbling, Capturing and Delegation**. This module teaches the fundamentals of Event propagation phases (Capturing, Target, Bubbling), stopPropagation(), Event Delegation pattern, Why delegation is high performance, Dynamic element event handling.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply Event propagation phases (Capturing, Target, Bubbling)
- Understand and apply stopPropagation()
- Understand and apply Event Delegation pattern
- Understand and apply Why delegation is high performance
- Understand and apply Dynamic element event handling
