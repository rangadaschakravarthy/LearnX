# Day 07 — Creating and Removing Elements

## Overview
Welcome to **Day 07 — Creating and Removing Elements**. This module teaches the fundamentals of createElement(), append() vs appendChild(), prepend(), before() & after(), remove(), replaceWith(), cloneNode(true vs false).

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply createElement()
- Understand and apply append() vs appendChild()
- Understand and apply prepend()
- Understand and apply before() & after()
- Understand and apply remove()
- Understand and apply replaceWith()
- Understand and apply cloneNode(true vs false)
