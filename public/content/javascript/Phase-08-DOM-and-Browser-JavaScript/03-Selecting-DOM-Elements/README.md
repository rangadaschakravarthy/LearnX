# Day 03 — Selecting DOM Elements

## Overview
Welcome to **Day 03 — Selecting DOM Elements**. This module teaches the fundamentals of getElementById(), getElementsByClassName(), getElementsByTagName(), querySelector(), querySelectorAll(), HTMLCollection vs NodeList, Static vs Live Collections.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply getElementById()
- Understand and apply getElementsByClassName()
- Understand and apply getElementsByTagName()
- Understand and apply querySelector()
- Understand and apply querySelectorAll()
- Understand and apply HTMLCollection vs NodeList
- Understand and apply Static vs Live Collections
