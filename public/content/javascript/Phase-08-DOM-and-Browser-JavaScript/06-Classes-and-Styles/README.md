# Day 06 — Classes and Styles

## Overview
Welcome to **Day 06 — Classes and Styles**. This module teaches the fundamentals of className property, classList API (add, remove, toggle, contains, replace), Inline styles via element.style, CSS property naming in JS, getComputedStyle().

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply className property
- Understand and apply classList API (add, remove, toggle, contains, replace)
- Understand and apply Inline styles via element.style
- Understand and apply CSS property naming in JS
- Understand and apply getComputedStyle()
