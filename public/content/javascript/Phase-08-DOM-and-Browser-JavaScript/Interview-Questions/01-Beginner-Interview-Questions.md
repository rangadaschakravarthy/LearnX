# Phase 8: Beginner Interview Questions

### Q1: What is the Document Object Model (DOM)?
The DOM is an object-oriented representation of an HTML document structured as a tree of node objects that JavaScript can read, traverse, and manipulate.

---

### Q2: What is the difference between `window` and `document`?
`window` is the global root object representing the browser window/tab environment. `document` is a property of `window` representing the loaded HTML document.
