# Day 12 — Forms and Form Handling

## Overview
Welcome to **Day 12 — Forms and Form Handling**. This module teaches the fundamentals of HTML Form elements & submission, submit event & preventDefault(), Reading input, checkbox, radio values, FormData API, Constraint validation (checkValidity, reportValidity, setCustomValidity).

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply HTML Form elements & submission
- Understand and apply submit event & preventDefault()
- Understand and apply Reading input, checkbox, radio values
- Understand and apply FormData API
- Understand and apply Constraint validation (checkValidity, reportValidity, setCustomValidity)
