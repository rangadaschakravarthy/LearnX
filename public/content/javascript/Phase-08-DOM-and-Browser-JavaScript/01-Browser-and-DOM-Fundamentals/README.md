# Day 01 — Browser and DOM Fundamentals

## Overview
Welcome to **Day 01 — Browser and DOM Fundamentals**. This module teaches the fundamentals of What is a browser?, JavaScript runtime in browser, Browser vs JavaScript language, Browser APIs, DOM & BOM introduction, Window & Document objects, Connecting JS to HTML.

## Learning Objectives
By the end of this day, you will be able to:
- Understand and apply What is a browser?
- Understand and apply JavaScript runtime in browser
- Understand and apply Browser vs JavaScript language
- Understand and apply Browser APIs
- Understand and apply DOM & BOM introduction
- Understand and apply Window & Document objects
- Understand and apply Connecting JS to HTML

---

## File Structure
- `Theory.md`: In-depth concept guide and syntax documentation.
- `Examples.html` & `Examples.js`: Runnable browser examples.

- `Output-Questions.md`: Predict-the-output questions.
- `Debugging.md`: Real-world browser debugging scenarios.
- `Interview-Questions.md`: Targeted technical interview questions.
- `Solutions/`: Complete solutions for exercises, output questions, and debugging.
