# 60 Debugging Exercises: Objects

## Scenario 1: Debugging Bug 1
**Broken Code:**
```js
function bug1(key, val) {
  return { key: val }; // Bug: Literal key "key" instead of computed dynamic key!
}
```
**Issue:** Unbracketed key is treated as literal property identifier "key".
**Correct Code:**
```js
function fix1(key, val) {
  return { [key]: val };
}
```
