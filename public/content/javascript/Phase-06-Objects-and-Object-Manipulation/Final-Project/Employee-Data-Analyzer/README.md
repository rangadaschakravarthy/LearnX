# Final Capstone Project: Employee Data Analyzer

Console-based JavaScript Employee Data Processing and Analytics Engine built purely with vanilla JavaScript objects, arrays of objects, higher-order methods, destructuring, spread, `Object.entries()`, and JSON.

## Features
- Add, update, search, filter, and sort employee records.
- Department salary analysis (highest/lowest/average per department).
- Skill search index and duplicate ID detection.
- Export summary reports to JSON format.
