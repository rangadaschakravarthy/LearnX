# Day 06 Mini-Project: Eligibility & Grade Analyzer

## Project Description
Build an interactive browser tool that accepts student marks, attendance percentage, age, and scholarship status, evaluating their pass/fail status, letter grade, and scholarship eligibility using clean `if/else if` chains and guard clauses.

---

## 🛠️ Concepts Applied
- `if`, `else if`, and `else` decision chains
- Compound logical conditions (`&&`, `||`)
- Guard clause validation
- Boundary testing

---

## 📁 Files Included
- `index.html`: Grade & Eligibility Analyzer UI interface.
- `script.js`: Evaluation logic script.
- `expected-output.md`: Expected browser outputs.
