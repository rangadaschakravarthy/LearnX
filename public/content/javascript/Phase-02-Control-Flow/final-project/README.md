# Phase 2 Final Capstone Project — JavaScript Logic Challenge Engine

## 1. Overview
The **JavaScript Logic Challenge Engine** is an interactive, browser-based sandbox and automated evaluation system for Phase 2: Control Flow & Program Logic.

## 2. Features
- **10 Core Logic Challenges**: Test mastery of `if/else`, `switch`, `for`, `while`, nested loops, and `for...of`/`for...in`.
- **Interactive Code Editor & Runner**: Run real-time JavaScript implementations directly in the web UI.
- **Automated Test Suite**: Executes unit test assertions with instant visual feedback (Passed / Failed badges).
- **Execution Step-by-Step Trace visualizer**: Inspect variables at each step.
- **Score Dashboard**: Tracks percentage completion and mastery score.

## 3. How to Run
1. Open `index.html` in any web browser.
2. Select a challenge from the sidebar.
3. Write your solution function in the editor area.
4. Click **Run Tests** to validate your code.
5. Alternatively, run `node script.js` for CLI verification.
