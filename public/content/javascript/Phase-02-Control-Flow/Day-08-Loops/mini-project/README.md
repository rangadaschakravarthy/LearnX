# Day 08 Mini-Project: Number Analysis Toolkit

## Project Description
Build an interactive Number Analysis Toolkit web application that calculates Prime checks, Factorials, Fibonacci sequences, Digit sums, and Number Reversals using clean `for` and `while` loops.

---

## 🛠️ Concepts Applied
- `for` and `while` loops
- Accumulators and mathematical logic
- Prime verification & digit extraction
- Pattern generation

---

## 📁 Files Included
- `index.html`: Number Analysis Toolkit UI.
- `script.js`: Mathematical loop utility script.
- `expected-output.md`: Expected browser output logs.
