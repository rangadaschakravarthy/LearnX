# Assessment Section 3 — Coding Challenges (25 Problems)

1. **FizzBuzz Custom Range**: Print numbers from `start` to `end` replacing multiples of 3 with "Fizz", 5 with "Buzz", both with "FizzBuzz".
2. **Matrix Diagonal Sum**: Calculate sum of main and anti-diagonals in square matrix.
3. **Array Chunking**: Split array into sub-arrays of maximum size `k`.
4. **Palindrome Substring Count**: Count total palindromic substrings in string.
5. **Flatten Nested Object**: Convert nested key-value object into single-level dotted path keys.
6-25. Comprehensive problem solving specifications covering binary search, prime factorization, custom set operations, and iterative tree traversal.
