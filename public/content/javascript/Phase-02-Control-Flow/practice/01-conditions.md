# Practice Module 01 — Simple Conditions (`if` / `else`)

Solve each of the following 15 problems. Write your code in Javascript and check your answers in `solutions/01-conditions-solutions.md`.

---

### Problem 1: Even or Odd
Write a function `isEven(n)` that returns `true` if `n` is an even number, otherwise `false`.

### Problem 2: Positive, Negative, or Zero
Write a function `checkSign(n)` that returns `"Positive"` if `n > 0`, `"Negative"` if `n < 0`, and `"Zero"` if `n === 0`.

### Problem 3: Voting Eligibility
Write a function `canVote(age)` that returns `true` if `age` is 18 or greater, otherwise `false`.

### Problem 4: Maximum of Two Numbers
Write a function `findMax(a, b)` that returns the larger of two numbers without using `Math.max()`.

### Problem 5: Pass or Fail
Write a function `checkPass(score)` that returns `"Pass"` if `score >= 50`, otherwise `"Fail"`.

### Problem 6: Multiple of Five
Write a function `isMultipleOfFive(n)` that returns `true` if `n` is evenly divisible by 5, otherwise `false`.

### Problem 7: Absolute Value
Write a function `getAbsoluteValue(n)` that returns the non-negative magnitude of `n` without using `Math.abs()`.

### Problem 8: Century Check
Write a function `isNewCentury(year)` that returns `true` if `year >= 2001`, otherwise `false`.

### Problem 9: Non-Empty String Check
Write a function `hasContent(str)` that returns `true` if `str` is a string with length greater than zero, otherwise `false`.

### Problem 10: Equal or Not
Write a function `areStrictlyEqual(a, b)` that returns `true` if `a` and `b` share both identical type and value.

### Problem 11: Speeding Fine Assessment
Write a function `checkSpeed(speed)` that returns `"FINE APPLIED"` if `speed > 60`, otherwise `"OK"`.

### Problem 12: Temperature Alert
Write a function `checkFreezing(celsius)` that returns `"FREEZING"` if `celsius <= 0`, otherwise `"NORMAL"`.

### Problem 13: Leap Year Century Boundary
Write a function `isCenturyYear(year)` that returns `true` if `year` ends in `00` (`year % 100 === 0`).

### Problem 14: Single Digit Check
Write a function `isSingleDigit(n)` that returns `true` if `n` is between -9 and 9 inclusive.

### Problem 15: Valid Age Range
Write a function `isValidHumanAge(age)` that returns `true` if `age` is between 0 and 120 inclusive.
