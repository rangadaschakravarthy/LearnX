# Practice Module 05 — Switch Statements & Expressions

Solve each of the following 15 problems using `switch`. Check solutions in `solutions/05-switch-statements-solutions.md`.

---

### Problem 1: Day Name Lookup
Convert number (1-7) to day name ("Monday"..."Sunday"). Default: "Invalid Day".

### Problem 2: Month Days Counter
Convert month number (1-12) to days count (assume non-leap year: Feb=28).

### Problem 3: Basic Calculator Dispatch
Given `(a, b, op)` where `op` is `"+"`, `"-"`, `"*"`, `"/"`, return calculation result.

### Problem 4: Role Access Level
Map role string ("admin", "editor", "viewer") to access level (3, 2, 1). Default: 0.

### Problem 5: Fall-through Season Lookup
Use fall-through cases to map month numbers to season names.

### Problem 6: HTTP Status Code Reason
Map codes (200, 301, 404, 500) to status text ("OK", "Moved Permanently", "Not Found", "Internal Server Error").

### Problem 7: File Extension MIME Type
Map extension (".html", ".css", ".js", ".json") to MIME type.

### Problem 8: Switch (true) Numeric Ranges
Use `switch(true)` to assign letter grade from score.

### Problem 9: Keyboard Arrow Command
Map key code ("ArrowUp", "ArrowDown", "ArrowLeft", "ArrowRight") to movement vector `{x, y}`.

### Problem 10: Roman Numeral Converter (1-5)
Convert integer 1-5 to Roman numerals ("I", "II", "III", "IV", "V").

### Problem 11: Priority Level Color Code
Map priority ("low", "medium", "high", "critical") to color ("green", "yellow", "orange", "red").

### Problem 12: Currency Symbol Resolver
Map currency code ("USD", "EUR", "GBP", "JPY", "INR") to symbol ("$", "€", "£", "¥", "₹").

### Problem 13: Order Status Transition Guard
Map order state ("pending", "processing", "shipped", "delivered") to next allowable action.

### Problem 14: Planet Distance Order
Map planet name (case-insensitive) to distance index from Sun (1 for Mercury to 8 for Neptune).

### Problem 15: Unit Conversion Router
Given `(val, unitFrom, unitTo)`: switch router for length conversions (m to km, cm to m, inch to cm).
