# Practice Module 08 — Nested Loops & Pattern Printing

Solve each of the following 15 problems. Check solutions in `solutions/08-nested-loops-solutions.md`.

---

### Problem 1: Right-Angled Triangle Pattern
Write `drawTriangle(rows)` returning array of star strings (`["*", "**", "***"...]`).

### Problem 2: Inverted Triangle Pattern
Write `drawInvertedTriangle(rows)` returning array (`["***", "**", "*"]`).

### Problem 3: Square Grid Generator
Write `generateGrid(size, char)` returning array of strings e.g. `["###", "###", "###"]`.

### Problem 4: Multiplication Table Grid (2D Array)
Write `createMultiplicationGrid(rows, cols)` returning 2D array of products (`grid[r][c] = (r+1)*(c+1)`).

### Problem 5: Prime Numbers Generator Up To N
Write `getPrimesUpTo(n)` using nested loop prime check.

### Problem 6: Matrix Transpose
Write `transposeMatrix(matrix)` converting rows to columns.

### Problem 7: Pyramid Pattern Generator
Write `drawPyramid(height)` returning centered star rows with appropriate leading spaces.

### Problem 8: 2D Array Sum
Write `sum2DArray(matrix)` summing all elements in a 2D array.

### Problem 9: Check Identity Matrix
Write `isIdentityMatrix(matrix)` checking if square matrix has 1s on main diagonal and 0s elsewhere.

### Problem 10: Find Duplicate Elements
Write `findDuplicates(arr)` using nested loops to find numbers appearing more than once.

### Problem 11: Bubble Sort Implementation
Write `bubbleSort(arr)` sorting numbers in ascending order using nested loops.

### Problem 12: Diamond Pattern Array
Write `drawDiamond(radius)` generating diamond pattern lines.

### Problem 13: Hollow Square Generator
Write `drawHollowSquare(size)` returning square with border characters and hollow interior spaces.

### Problem 14: Matrix Row Sums
Write `getRowSums(matrix)` returning array of sums for each row.

### Problem 15: Checkerboard Generator
Write `drawCheckerboard(rows, cols)` returning grid alternating `"X"` and `"O"`.
