# Practice Module 04 — Ternary Operator (`?:`)

Solve each of the following 15 problems using ternary expressions. Check solutions in `solutions/04-ternary-operator-solutions.md`.

---

### Problem 1: Inline Min/Max
Write `getMin(a, b)` returning smaller value using ternary.

### Problem 2: Adult Status Message
Write `getAdultMessage(age)` returning `"Adult"` if `>= 18`, else `"Minor"`.

### Problem 3: Odd/Even Label
Write `getOddEvenLabel(n)` returning `"Odd"` or `"Even"`.

### Problem 4: Plural Form Formatter
Write `formatItemCount(count, singularWord)` returning e.g. `"1 apple"` vs `"5 apples"`.

### Problem 5: Absolute Value Ternary
Write `absTernary(n)` returning magnitude without `Math.abs`.

### Problem 6: Default Value Fallback
Write `getDisplayName(name)` returning `name` if truthy, else `"Guest"`.

### Problem 7: Chained Grade Rating
Write `ratePerformance(score)` returning `"High"` (>=80), `"Medium"` (>=50), or `"Low"`.

### Problem 8: Boolean Toggle Switch
Write `toggleStatus(current)` returning `"active"` if `"inactive"`, else `"inactive"`.

### Problem 9: Discount Applicator
Write `applyDiscount(price, isMember)` returning price with 15% discount if member.

### Problem 10: Sign Classifier
Write `classifySign(n)` returning `"Positive"`, `"Negative"`, or `"Zero"`.

### Problem 11: Dark/Light Mode Theme Class
Write `getThemeClass(isDarkMode)` returning `"theme-dark"` or `"theme-light"`.

### Problem 12: Shipping Cost Short-hand
Write `quickShipping(orderAmount)` returning `0` if `>= 50`, else `5.99`.

### Problem 13: Login Greeting
Write `getGreeting(user)` returning `"Welcome back, " + user.name` if user exists, else `"Please sign in"`.

### Problem 14: Leap Year Ternary
Write `isLeapYearTernary(year)` returning boolean using a single ternary expression.

### Problem 15: Safe Division Guard
Write `safeDivide(a, b)` returning `a / b` if `b !== 0`, else `null`.
