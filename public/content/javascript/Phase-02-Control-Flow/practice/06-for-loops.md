# Practice Module 06 — Traditional `for` Loops

Solve each of the following 15 problems using standard `for` loops. Check solutions in `solutions/06-for-loops-solutions.md`.

---

### Problem 1: Sum 1 to N
Function `sumToN(n)` returns the sum of numbers from 1 to `n`.

### Problem 2: Factorial Calculation
Function `factorial(n)` returns `n!`. Return 1 for `n=0`.

### Problem 3: Print Even Numbers
Function `getEvensUpTo(n)` returns an array of all even numbers from 0 up to `n`.

### Problem 4: Countdown Array Generator
Function `generateCountdown(start)` returns array `[start, start-1, ..., 0]`.

### Problem 5: Array Sum
Function `sumArray(arr)` calculates sum of array elements using index lookup.

### Problem 6: Multiplication Table Array
Function `getMultiplicationTable(num, limit)` returns array of strings e.g. `"5 x 1 = 5"`.

### Problem 7: Count Character Occurrences
Function `countChar(str, target)` counts how many times `target` appears in `str`.

### Problem 8: Maximum Element in Array
Function `findMaxArray(arr)` returns largest number in array without `Math.max`.

### Problem 9: Array Reverse In-Place / Manual
Function `reverseArrayManual(arr)` returns a new array with elements reversed using a backward loop.

### Problem 10: Fibonacci Sequence Generator
Function `generateFibonacci(n)` returns array of first `n` Fibonacci numbers (`[0, 1, 1, 2, 3, 5...]`).

### Problem 11: Alternate Case String
Function `toAlternateCase(str)` converts characters at even indices to uppercase and odd to lowercase.

### Problem 12: Skip Multiples of Three
Function `sumExcludeMultiplesOfThree(n)` sums numbers 1 to `n`, skipping any number divisible by 3 (`continue`).

### Problem 13: Linear Search First Index
Function `findFirstIndex(arr, target)` returns first index of `target` or -1 using `break`.

### Problem 14: Compute Powers of Two
Function `getPowersOfTwo(count)` returns array `[1, 2, 4, 8, 16...]` up to `count` elements.

### Problem 15: Array Element Frequency Counter
Function `countFrequency(arr, val)` returns number of times `val` occurs in `arr`.
