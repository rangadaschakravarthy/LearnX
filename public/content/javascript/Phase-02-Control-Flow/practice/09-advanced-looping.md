# Practice Module 09 — Advanced Looping (`for...of`, `for...in`, `Object.*`)

Solve each of the following 15 problems. Check solutions in `solutions/09-advanced-looping-solutions.md`.

---

### Problem 1: Array Element Printer with `for...of`
Print array items uppercase.

### Problem 2: String Vowel Counter with `for...of`
Count total vowels in string.

### Problem 3: Object Key List with `for...in`
Return list of own property names.

### Problem 4: Sum Object Numeric Values with `Object.values`
Sum all numeric properties in an object.

### Problem 5: Key-Value Formatter with `Object.entries`
Format object into array of `"key: value"` strings.

### Problem 6: Array Index & Value Pair with `.entries()` and `for...of`
Return formatted array `["#0: Apple", "#1: Banana"]`.

### Problem 7: Filter Object by Value Threshold
Return new object containing only entries where numeric value >= threshold.

### Problem 8: Count Property Types in Object
Count how many string, number, boolean properties exist in object using `for...in`.

### Problem 9: Labeled Loop Matrix Target Search
Find `[row, col]` of target value in 2D array breaking out immediately when found.

### Problem 10: Deep Object Property Scanner
Recursively count primitive property keys in nested object.

### Problem 11: Set Deduplication with `for...of`
Remove array duplicates using `Set` and `for...of`.

### Problem 12: Object Key Inversion
Swap keys and values of object using `Object.entries()`.

### Problem 13: Calculate Average Grade from Student Object
Given `{ alice: 90, bob: 85 }`, calculate average grade using `Object.values()`.

### Problem 14: Labeled Loop Department Audit
Skip remaining department employees if banned user tag encountered.

### Problem 15: Merge Object Arrays by Key
Join array of user objects with array of order objects matching `userId`.
