# Day 07 Mini-Project: Console Menu Application

## Project Description
Build an interactive console menu application that displays menu options (`1. Add`, `2. Subtract`, `3. Multiply`, `4. Divide`, `5. Exit`), takes user input choices, and executes corresponding mathematical handlers using `switch`.

---

## 🛠️ Concepts Applied
- `switch` statement action dispatching
- Strict equality case matching
- Default fallback handling
- Menu option routing

---

## 📁 Files Included
- `index.html`: Interactive Console Menu App UI.
- `script.js`: Menu router and arithmetic handler script.
- `expected-output.md`: Expected browser output.
