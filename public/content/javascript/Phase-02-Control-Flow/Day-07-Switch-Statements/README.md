# Day 07: Switch Statements

## Day Objective
Master the `switch` statement syntax, understand strict `case` matching semantics (`===`), master `break` execution, leverage intentional fall-through, configure fallback `default` cases, evaluate switch statements with string literals and boolean expressions, and master the decision matrix for choosing between `switch` and `if/else`.

---

## 🎯 Topics Covered
1. **Switch Syntax & Case Matching**: Expression evaluation, `case value:`, strict equality comparison (`===`) behavior.
2. **`break` & Fall-Through Mechanics**: Role of `break`, accidental fall-through bugs, intentional fall-through patterns (grouping multiple cases).
3. **`default` Case & String Matching**: Placement of `default`, handling unexpected values, switching over String literals.
4. **Switch with Range Expressions**: Advanced pattern `switch (true)` for evaluating comparison ranges.
5. **Switch vs `if/else` Decision Matrix**: Comparative performance, readability trade-offs, when to choose `switch` vs `if/else`.
