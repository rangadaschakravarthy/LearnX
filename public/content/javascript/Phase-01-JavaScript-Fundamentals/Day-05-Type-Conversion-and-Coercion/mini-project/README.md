# Day 05 Mini-Project: Type Conversion Playground

## Project Description
Build an interactive Type Conversion Playground web application that allows users to test explicit conversion functions (`String()`, `Number()`, `Boolean()`, `parseInt()`), test implicit coercion behavior across math operations, test Abstract Equality (`==`) vs Strict Equality (`===`), and inspect truthy/falsy values in real-time.

---

## 🛠️ Concepts Applied
- Explicit Conversion (`String`, `Number`, `Boolean`, `parseInt`)
- Implicit Coercion (`+`, `-`, `*`, `/`)
- Abstract Equality Comparison algorithm (`==` vs `===`)
- Truthy & Falsy value matrix

---

## 📁 Files Included
- `index.html`: Interactive Conversion Lab Interface.
- `script.js`: Core conversion engine logic.
- `expected-output.md`: Expected browser outputs.
