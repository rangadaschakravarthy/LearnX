# Phase 1 Final Project: JavaScript Fundamentals Interactive Playground

## Project Overview
The **JavaScript Fundamentals Interactive Playground** is a comprehensive browser application built to synthesize and test all concepts learned in Phase 1 (Days 1 through 5).

---

## 🚀 Key Modules & Interactive Features

1. **Variables & Scope Simulator**: Interactively test `var`, `let`, and `const` declarations across global, function, and block scope boundaries; observe hoisting and Temporal Dead Zone error traps.
2. **Data Type & Typeof Inspector**: Evaluate JavaScript's 7 primitive types vs reference types, view memory allocation rules (Stack vs Heap), and inspect `typeof` quirks vs `Object.prototype.toString.call()`.
3. **Operator & Short-Circuit Evaluator**: Experiment with arithmetic, prefix/postfix increment, logical short-circuiting (`&&`, `||`), optional chaining (`?.`), and nullish coalescing (`??`).
4. **Type Coercion & Equality Lab**: Compare Loose Equality (`==`) vs Strict Equality (`===`), trace Abstract Equality coercion steps, and test truthy/falsy evaluation matrix.

---

## 🛠️ Tech Stack & Architecture
- **HTML5**: Semantic UI structure with accessible controls.
- **Vanilla CSS3**: Modern dark-mode aesthetic with CSS Grid/Flexbox, sleek glassmorphism panels, vibrant accents, and smooth transitions.
- **Modern ES6+ JavaScript**: Clean, strict-mode (`"use strict"`), modular client-side logic.
