# Day 04: Operators

## Day Objective
Master JavaScript operators: Arithmetic, Compound Assignment, Increment/Decrement (Prefix `++x` vs Postfix `x++`), Strict (`===`) vs Loose (`==`) Comparison, Logical operators (`&&`, `||`, `!`), Short-Circuit evaluation mechanics, Ternary operator, Unary operators, Modern ES2020+ operators (Nullish Coalescing `??`, Optional Chaining `?.`, Logical Assignment `&&=`, `||=`, `??=`), and Operator Precedence rules.

---

## 🎯 Topics Covered
1. **Arithmetic & Assignment**: `+`, `-`, `*`, `/`, `%`, `**`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=`, Prefix (`++x`) vs Postfix (`x++`).
2. **Comparison & Equality**: `>`, `<`, `>=`, `<=`, Loose Equality (`==`), Loose Inequality (`!=`), Strict Equality (`===`), Strict Inequality (`!==`).
3. **Logical Operators & Short-Circuiting**: `&&`, `||`, `!`, Short-circuit evaluation, returning operand values instead of booleans.
4. **Ternary, Unary & Logical Assignment**: `condition ? val1 : val2`, unary `+`, `-`, `!`, `typeof`, `delete`, `void`, logical assignment (`&&=`, `||=`, `??=`).
5. **Nullish Coalescing, Optional Chaining & Precedence**: `??` vs `||`, `?.` for objects/arrays/functions, operator precedence order.
