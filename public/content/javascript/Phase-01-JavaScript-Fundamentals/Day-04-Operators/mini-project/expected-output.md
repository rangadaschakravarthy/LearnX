# Day 04 Mini-Project Expected Output

When evaluating `10 + 5 * 2 ** 3`:
- Evaluated Result: `50` (Because `2 ** 3 = 8`, then `5 * 8 = 40`, then `10 + 40 = 50`)
- Result Type: `number`

When evaluating `0 || "Fallback"`:
- Evaluated Result: `Fallback` (0 is falsy)
- Result Type: `string`

When evaluating `0 ?? "Fallback"`:
- Evaluated Result: `0` (0 is not null or undefined)
- Result Type: `number`
