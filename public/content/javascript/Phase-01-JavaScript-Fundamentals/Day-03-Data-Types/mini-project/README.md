# Day 03 Mini-Project: Data Type Explorer

## Project Description
Build an interactive Data Type Explorer web application that accepts user input or evaluated expressions, analyzes their exact JavaScript data type, memory allocation mode (Stack vs Heap), immutability status, and `typeof` results.

---

## 🛠️ Concepts Applied
- Primitive vs Reference types
- `typeof` operator & `Object.prototype.toString.call()`
- `Array.isArray()` and `Number.isNaN()`
- Value immutability inspector

---

## 📁 Files Included
- `index.html`: Interactive Type Explorer UI.
- `script.js`: Core expression type parser and evaluator.
- `expected-output.md`: Reference browser outputs.
