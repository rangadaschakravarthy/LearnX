# Day 01: Introduction to JavaScript

## Day Objective
Understand the origins of JavaScript, how engines parse and execute code, runtime environments, script tag loading attributes (`defer` vs `async`), Strict Mode (`"use strict"`), statements vs expressions, DevTools, and basic syntax rules.

---

## 🎯 Topics Covered
1. **JavaScript Origins & History**: Brendan Eich, Netscape, Mocha, LiveScript, ECMAScript, TC39, ES5 vs ES6+.
2. **JavaScript Engines & Runtimes**: V8, SpiderMonkey, JSC, AST Parsing, Interpreter, JIT Compiler, Browser vs Node.js vs Bun/Deno.
3. **First Program & DevTools**: `console.log`, DevTools (Console, Sources, Breakpoints).
4. **Console API, Comments & Syntax**: `console.error/warn/table/dir`, single-line & multi-line comments, identifiers, reserved keywords, statements, expressions, block syntax, Automatic Semicolon Insertion (ASI).
5. **Script Loading & Strict Mode**: `<script>`, `defer`, `async`, inline vs external script placement, `"use strict"` enforcement.

---
