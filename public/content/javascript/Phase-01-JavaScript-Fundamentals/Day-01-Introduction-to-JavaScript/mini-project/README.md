# Day 01 Mini-Project: JavaScript Console Introduction Lab

## Project Description
Build a interactive developer lab inside the browser to showcase Console API formatting, script execution logging, strict mode verification, and system environment info output.

---

## 🛠️ Concepts Applied
- `console.log()`, `console.warn()`, `console.error()`, `console.table()`, `console.time()`
- Strict Mode (`"use strict"`)
- External script linking with `defer`
- DOM interactions for output status rendering

---

## 📁 Files Included
- `index.html`: Web interface for triggering console lab commands.
- `script.js`: Clean JavaScript file containing strict mode application logic.
- `expected-output.md`: Reference screenshot/text output for expected browser console log output.
