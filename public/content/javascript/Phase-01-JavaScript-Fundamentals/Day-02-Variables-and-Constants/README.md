# Day 02: Variables and Constants

## Day Objective
Master the variable lifecycle (Declaration, Initialization, Assignment, Reassignment), compare `var`, `let`, and `const`, understand function scope vs block scope, learn hoisting mechanics, explore the Temporal Dead Zone (TDZ), follow identifier naming rules, and understand object/array mutation under `const`.

---

## 🎯 Topics Covered
1. **Variable Lifecycle**: What is a variable, declaration vs initialization vs assignment vs reassignment.
2. **`var` vs `let` vs `const`**: Function scope vs block scope, redeclaration rules, mutation vs binding reassignment.
3. **Naming Rules & Conventions**: Valid identifiers (`$`, `_`, letters, numbers), reserved words, `camelCase`, `PascalCase`, `UPPER_SNAKE_CASE`.
4. **Scope Boundaries**: Global scope, Function scope, Block scope, scope leakage with `var`.
5. **Hoisting & TDZ**: `var` hoisting (`undefined`), `let`/`const` hoisting, Temporal Dead Zone (`ReferenceError`), function hoisting.
