# Day 02 Mini-Project: Personal Information Variables Program

## Project Description
Create an interactive profile inspector application that uses `let` for mutable user state, `const` for fixed user identity constants, and handles object mutation vs reassignment cleanly.

---

## 🛠️ Concepts Applied
- `let`, `const`, and block scope
- Naming conventions (`camelCase`, `UPPER_SNAKE_CASE`)
- Object mutation under `const`
- TDZ & scope boundary safety checks

---

## 📁 Files Included
- `index.html`: Browser UI card interface.
- `script.js`: Clean JavaScript profile management script.
- `expected-output.md`: Expected visual and console log outputs.
